# CC Autopilot and altitude controller for gyro and thruster based flyer with Aeronautics
if you play on Project crowbar, the use of this software is prohibited for any commercial use(ex: taxi company)

## Installation
print `wget run https://raw.githubusercontent.com/Gelodix/flyer/main/installer.lua` in your computer.

print `wget run https://raw.githubusercontent.com/Gelodix/flyer/main/remote_installer.lua` to install the rednet client and be able to control your ship from far away.
